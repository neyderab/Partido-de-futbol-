# Equipos de Futbol

Este proyecto fue realizado para practicar programacion orientada a objetos usando Python.

El programa simula algunos elementos de un equipo de futbol, como jugadores, entrenadores, estadios, equipos, ligas y partidos.

## Lo que incluye

* crear jugadores y registrar sus goles
* transferir y retirar jugadores
* crear entrenadores y dar instrucciones
* crear estadios
* crear equipos de futbol
* contratar entrenadores
* agregar jugadores a un equipo
* comparar equipos por sus trofeos
* crear una liga y mostrar los equipos
* simular un partido

## Como usarlo

Para ejecutar el programa solo necesitas tener Python instalado y ejecutar el archivo:

```bash
python football_team_project.py
```

El proyecto busca mostrar de una forma sencilla como funcionan las clases, objetos, atributos, metodos y la herencia en Python.
